# Artículo 216

En caso de que las condiciones a que se refiere el [artículo anterior](articulo-215.md) no subsistan, o bien, no se cumpla con las disposiciones legales aplicables, la [Secretaría](articulo-2o.md) prevendrá al interesado para que subsane las anomalías encontradas y le otorgará un plazo de hasta ciento ochenta días para corregirlas.

Cuando implique riesgo para la salud podrá suspender temporalmente las actividades afectadas.

La falta de cumplimiento de las correcciones señaladas por la Secretaría, serán causa de suspensión de la autorización otorgada, y la Secretaría le concederá un nuevo plazo de noventa días para corregir las irregularidades. En caso de que no se cumpla con lo indicado por la Secretaría dentro de este último plazo, se revocará la autorización.
