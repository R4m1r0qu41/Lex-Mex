# 3o

Los recursos interpuestos antes de la vigencia de este Código y que aún no hubieren sido admitidos o desechados se admitirán, siempre que este mismo Código o en las leyes anteriores se conceptuarán procedentes, se substanciarán conforme a este mismo ordenamiento.
