# Quinto

Para la determinación de la [Remuneración Anual Máxima](articulo-10.md) aplicable para el ejercicio fiscal de 2022 conforme a lo previsto en el artículo [12](articulo-12.md), inciso b), de esta Ley, se tomará como base la aprobada para el Presupuesto de Egresos de la Federación para el Ejercicio Fiscal 2021.
