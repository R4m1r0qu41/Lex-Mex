# Artículo 36

La [Dirección General](articulo-2.md) podrá ordenar en cualquier momento la práctica de visitas de verificación, inclusive de manera previa para otorgar una autorización con el fin de comprobar que se cuenta con los medios humanos, de formación, técnicos, financieros y materiales para brindar los servicios de forma adecuada.

Para estos efectos podrá celebrar convenios de colaboración con las autoridades competentes de las entidades federativas.

Artículo reformado DOF 27-01-2011
