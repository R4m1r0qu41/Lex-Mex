> Título NOVENO · Capítulo Único

# Artículo 101

Para efectos de este Reglamento, dentro de las bebidas no alcohólicas, productos para prepararlas y congelados de las mismas quedan comprendidos los siguientes: I. Aguas envasadas; II. Bebidas saborizadas no alcohólicas; III. Congelados de las anteriores; IV. Polvo, y V. Jarabe.
