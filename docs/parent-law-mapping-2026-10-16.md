# Regulation to parent-law mapping — 2026-10-16

Source of truth: the `parent_instrument_id` field in each regulation's adapter (`adapters/diputados/<slug>.json`). Decision and rule: `docs/decisions.md`, "Parent-law linking for regulations". Generated by script from the committed official titles and cross-checked against each regulation's definitions entry; not hand-reviewed per citation.

## Mapped (123 regulations)

92 by exact title, 28 by title prefix, 3 by manual override (`reg-lfmzaah` → `lfmzaah`, `reg-lgamvlv` → `lgamvlv`, `reg-lmin` → `lmin`; the regulation title uses an older or pluralised name of the same law).

| Regulation | Reason |
|---|---|
| `reg-art121-122-lft`, `reg-lfpc-art122`, `reg-lfif-art95` | title names an article of the law, not the law; no bare-Ley citations to resolve |

To add or change a parent: edit the adapter field, run `lex-mex link --all`, and read the diff. A bare `Ley` linked to a wrong parent would show as edges whose cited articles do not fit the regulation.
