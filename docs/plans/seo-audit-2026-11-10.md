## P0
1. **Provisions are unreachable by link.** The instrument index shows 5 items (max 10 with `?limit`), the rest sits behind `?cursor=`, which is served `noindex, nofollow` (`worker/index.ts:24`); non-article pages are capped at 16,384 bytes (`query-http.mjs:78`). Article pages have no breadcrumb, prev/next or hub link. About 860 of 870 pages have no crawlable inbound link, so discovery rests on one sitemap. *Fix:* server-rendered hubs (instruments; each instrument with a plain link to every provision, no cursor), breadcrumbs and prev/next on articles.
2. **`/lex-mex/` is a JS shell behind a 307** (`app/lex-mex/route.ts`; `public/lex-mex/index.html`) and the sitemap lists the redirecting URL. *Fix proposed by auditor:* serve a 200 hub there and drop the 307. *Session disposition:* the 307 is a documented, tested and verified contract and the reader file is byte-signed, so keep it; make `/lex-mex/mx/` the crawlable front door and decide separately whether to retire the 307 (operator).

## P1
3. **Rate limiter** (120/min per IP, 600/min shared per location) applies to crawlers; a 429 slows Googlebot and persistent errors can drop URLs. *Disposition:* 870 URLs is small; watch 429s after submitting the sitemap; no bot exemption until a verified-bot signal is confirmed to be available on this plan.
4. **Titles, h1, descriptions use only the acronym** (`LRITF · Artículo 11 — Lex-Mex`); people type the full name or "Ley Fintech". Text-first ordering (provenance currently precedes the article), English tokens (`effective`, `machine_accepted`) in a Spanish page, text as one `<pre><span>`. *Disposition:* build titles from `instrument.title` and `short_name`; do not hard-code "Ley Fintech" or translate status tokens without the operator; keep the `<pre>` block (reflowing changes the bytes behind `text_sha256`).
5. **Canonical strategy.** Stable release-free canonical plus pinned page canonicalising to it; sitemap, hubs and JSON-LD use the stable URL; keyword-bearing Spanish segments (`articulo`, `transitorio`, `anexo`). Retired pins: auditor's preferred option (200 "superseded" page with the old text, `noindex`) is **not possible** because retired releases' text is not retained. *Disposition:* 404 with a pointer to the stable URL (a redirect would substitute different text under a pinned citation).
6. **hreflang:** only where an English counterpart exists. Articles are Spanish-only; add an English hub later with reciprocal tags.
7. **Sitemaps:** two competing files (root `sitemap.xml` with 3 site pages plus 870 pinned lines; minified `/lex-mex/agents/sitemap.xml`). *Fix:* one index plus one file per instrument, stable URLs only, `lastmod` only if truthful, drop `changefreq`/`priority`; submit to Search Console and Bing; IndexNow for Bing.
8. **`Cache-Control: no-store`** on article pages (`query-http.mjs:11`): no conditional requests; every crawl hits the Worker and limiter. *Fix:* cacheable headers plus `ETag` (only useful if the handler answers `If-None-Match` with 304).
9. **Structured data:** `Legislation` and its properties are valid (no Google rich result exists for it). Missing: fuller `name`, `alternateName`, `legislationType`, `legislationDateVersion`, `dateModified`, `BreadcrumbList`, `LegislationObject` encodings for the Markdown/JSON twins. Do not set `legislationLegalForce`.

## llms.txt and Markdown: evidence
Google's Illyes and Mueller said Google does not use `llms.txt` (secondary sources); Cloudflare's "Markdown for Agents" (Feb 2026) serves Markdown for `Accept: text/markdown`, which Claude Code sends. A Spanish search returned an mLey `.md` twin, so twins get fetched; no evidence they confer a ranking advantage. Real value for agents is plain static text-first HTML, clean URLs and internal links; treat `llms.txt` and `.md` twins as cheap extras.

## Benchmark
Searches for the Spanish phrases returned mley.mx first, then sdv.com.mx, vLex, diputados.gob.mx; not leg4ll4bs.com. The milestone that is reachable now is *indexed*, not *outranking*. The acronym alone is a weak query; the full law name or "Ley Fintech" is what people type.
