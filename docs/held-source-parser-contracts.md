# Held-source parser and review contracts

The nested-instrument adapter option is an explicit source-backed boundary profile. Marker strings match normalized block prefixes exactly and must occur once; wrapper, own-body start and following-article boundary must be ordered. The containing title must be corroborated before the wrapper. A single outer transitory section and corroborated closing signature/appendix boundary are required. Missing, repeated or reversed boundaries fail closed. `nested_instrument` and legacy `separate_enactment` are mutually exclusive.

Profiles preserve the source's formal containing-act title and use `containing_act` ownership and neutral `:containing-act:` evidence IDs. Substantive sibling material (including quoted LFPRH reforms) remains one typed `containing_article` evidence region; it is never parsed as the nested instrument's articles or transitories. Wrapper/preamble material and outer transitories are retained separately. No legal kind, commencement date or effect is inferred. Legacy decree evidence, IDs and exports remain compatible.

Source-backed fixtures establish LCMOPFIH15+5 own/8 outer; LISIPL7+0 own/7 outer; LFIIEDB141+1 own/8 outer. LFIIEDB's first own title/chapter are retained, and its closing signature prevents the next, unrelated DOF decree entering the instrument. The profile for an official DOF issue configures exact whole-line page headers. A structural opening quote is removed only before a numeric nested article heading; body quotation marks and acquisition bytes remain unchanged.

The exact `historical_superseded_reference_outdated` reference status requires an embedded `outdated_reference_approval`. Adapter `outdated_reference_approvals` match source provision, exact span and character offsets, intended instrument/provision, canonical source-text SHA256 and acquired-source SHA256. The record stores reviewer, rationale, decision artifact path and SHA256, and software `captured_at`; a reviewer-supplied timestamp is optional and never synthesized. Every approval must match exactly one missing-target edge. Changed text, ambiguous/duplicate approval, available target or acquisition drift fails closed. Unapproved missing targets still fail validation. The citation remains text and receives no live link; exports display the reviewed stale-reference notice. Ordinary reparsing/relinking refuses to replace or clear persisted review records.

`source_repeal_notice` records a reviewer-authorized instrument-level historical notice bound to its acquired-source hash and exact printed `Ley Abrogada DOF DD-MM-YYYY` header, plus formal DOF locator/hash and optional existing successor identity. It sets only instrument status `repealed`; it never assigns provision states or inferred effective dates. Exports show a historical abrogation line. `captured_at` is capture time, not the reviewer's decision time. A missing or altered source header/hash, unofficial formal host, self-successor or absent successor fails admission. Persisted notices cannot be cleared/replaced by an ordinary rerun.

`source_repeal_notice` may instead carry a `successor_clause` basis when the retained source has no abrogation header (`reg-lfmn`). It names `successor_instrument_id`, the abrogating `provision_id` (which must belong to that successor) and the provision's canonical text SHA-256; `source_note` must be a verbatim, whitespace-normalized quotation of that provision, and `source_sha256` still binds the instrument's own acquired source. Validation resolves the successor corpus and fails closed on a missing successor or provision, changed provision text, an unquoted note, acquisition drift, a self-successor, or a clause owned by another instrument. A successor-clause notice never satisfies the header check and vice versa. Header-basis notices omit the field, so existing canonical bytes are unchanged. Exports cite the abrogating provision instead of a Cámara header. As before, only instrument status is set; no effect date or provision state is inferred.

The LGAG legacy partition additionally accepts an ordinal sibling with a body containing only ASCII dots, using the existing dot-only classifier. Its source fixture preserves45+2 own and elided sibling+3 outer transitories; a substantive sibling does not qualify.

The PEF substantive-annex option flushes its final transitory at the exact parliamentary SALÓN signature prefix, skips signature apparatus, then preserves the configured annex tail. Flattened table citation sequence `artículo 0 74` is left unlinked; neither target0 nor an invented target74 is emitted. Canonical source text and table value0 remain unchanged. Ordinary article74 citations still resolve. This does not reconstruct PDF table layout.

An official compilation without the Diputados reform banner may opt into reform evidence only where a configured main-document stop marker is also recognized as an amending-act title. Publication notes accept the official `Publicado en el DOF el ...` form alongside the long publisher name. OAG source fixtures preserve29 reform-transitory clauses across10 publication dates, including6 in2021, while exact adapter header lines remove repeated page furniture. This records source evidence, not legal effect.
